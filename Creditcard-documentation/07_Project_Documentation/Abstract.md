# Abstract

## Overview

The rapid growth of digital banking has significantly increased the number of credit card applications processed by financial institutions. Traditional manual evaluation methods are often time-consuming, inconsistent, and prone to human error. To address these challenges, this project presents a **Credit Card Approval Prediction System** that leverages Machine Learning techniques to automate the approval process.

The system analyzes applicant information such as income, employment status, education, credit history, and other financial attributes to predict whether a credit card application should be approved or rejected. Historical applicant data is preprocessed, cleaned, and transformed before training multiple Machine Learning classification algorithms. The best-performing model is selected based on evaluation metrics such as accuracy, precision, recall, and F1-score.

The trained model is deployed using the Flask framework, allowing users to interact with the prediction system through a user-friendly web interface. Users can submit applicant details and receive real-time predictions.

This project demonstrates how Machine Learning can support financial institutions in making faster, more accurate, and consistent credit approval decisions while reducing operational costs and improving customer satisfaction.
