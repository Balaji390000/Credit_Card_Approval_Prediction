---

## Implementation Steps

### Step 1: Data Collection

Historical applicant data was collected in CSV format.

### Step 2: Data Preprocessing

The dataset was cleaned by handling missing values, encoding categorical variables, and scaling numerical features.

### Step 3: Model Training

Multiple Machine Learning algorithms were trained and compared.

### Step 4: Model Evaluation

Performance was evaluated using accuracy, precision, recall, and F1-score.

### Step 5: Flask Integration

The selected model was integrated into a Flask web application for real-time prediction.

### Step 6: Deployment

The application was tested locally and prepared for deployment.
