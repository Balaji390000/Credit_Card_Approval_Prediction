# Deployment Guide

## Overview

The application can be deployed locally or on cloud platforms.

---

## Local Deployment

### Clone Repository

```bash
git clone https://github.com/yourusername/Credit-Card-Approval-Prediction.git
```

### Navigate

```bash
cd Credit-Card-Approval-Prediction
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Start Application

```bash
python app.py
```

## Deployment Checklist

- Install dependencies
- Upload trained model
- Configure Flask
- Test endpoints
- Verify predictions

---

## Verification

After deployment:

- Home page loads successfully.
- Prediction works.
- No runtime errors.
- Application is accessible.
