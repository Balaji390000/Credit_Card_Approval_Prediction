# User Manual

## Introduction

The Credit Card Approval Prediction System is designed to help users predict whether a credit card application is likely to be approved.

---

## Steps to Use

### Step 1

Open the application in a web browser.

---

### Step 2

(Optional) Login using valid credentials.

---

### Step 3

Navigate to the Prediction page.

---

### Step 4

Enter applicant details such as:

- Age
- Gender
- Income
- Employment Status
- Education
- Credit History

---

### Step 5

Click **Predict**.

---

### Step 6

View the prediction result.

---

### Step 7

(Optional) View previous prediction history.

---

## Tips

- Enter accurate information.
- Do not leave mandatory fields empty.
- Review prediction carefully.
- Repeat prediction for another applicant if required.

---

## Troubleshooting

| Problem | Solution |
|----------|----------|
| Application not opening | Verify Flask server is running |
| Prediction not generated | Check input fields |
| Page not loading | Restart Flask server |
| Model error | Verify trained model file exists |

---

## Conclusion

The application provides a fast, reliable, and user-friendly interface for predicting credit card approval decisions using Machine Learning.
