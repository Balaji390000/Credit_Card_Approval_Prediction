# Sprint Planning

## Overview

The project was divided into multiple development sprints to ensure incremental progress and continuous evaluation.

---

## Sprint 1

### Objective

Project Planning and Dataset Collection

### Tasks

- Define project objectives
- Collect dataset
- Understand dataset
- Perform initial analysis

---

## Sprint 2

### Objective

Data Preprocessing

### Tasks

- Handle missing values
- Remove duplicates
- Encode categorical features
- Normalize data

## Sprint 3

### Objective

Machine Learning Development

- Train multiple algorithms
- Compare model performance
- Select best model

## Sprint 4

### Objective

Deployment

### Tasks

- Model integration

---

## Sprint 5

### Objective

Testing and Documentation

### Tasks

- Test application
- Fix bugs
