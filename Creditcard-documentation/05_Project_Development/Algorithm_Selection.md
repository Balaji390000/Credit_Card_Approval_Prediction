# Algorithm Selection

## Overview

Different classification algorithms were evaluated to identify the model that provides the highest prediction accuracy and generalization capability.

---

## Algorithms Considered

| Algorithm | Purpose |
|-----------|----------|
| Logistic Regression | Baseline linear classifier |
| Decision Tree | Rule-based classification |
| Random Forest | Ensemble learning |
| Support Vector Machine (SVM) | Margin-based classification |
| K-Nearest Neighbors (KNN) | Instance-based learning |
| Naïve Bayes | Probabilistic classification |

---

## Selection Criteria

The best algorithm was selected based on:

- Accuracy
- Precision
- Recall
- F1 Score
- Execution Time
- Robustness

---

## Final Model

The algorithm with the highest evaluation metrics and consistent performance on unseen data was selected as the final prediction model.
