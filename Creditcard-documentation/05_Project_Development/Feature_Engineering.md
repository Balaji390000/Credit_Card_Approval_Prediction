# Feature Engineering

## Overview

Feature Engineering improves model performance by selecting, transforming, and creating meaningful variables from the original dataset.

---

## Feature Selection

Important features influencing credit card approval include:

- Annual Income
- Employment Status
- Credit History
- Education Level
- Age
- Existing Loans

These features contribute significantly to the prediction process.

---

## Feature Transformation

The following transformations were applied:

- Encoding categorical variables
- Scaling numerical values
- Removing redundant features
- Converting boolean values into binary format

---

## Benefits

Feature engineering helps:

- Improve prediction accuracy
- Reduce overfitting
- Simplify the model
- Enhance computational efficiency
