# Dataset Description

## Overview

The Credit Card Approval Prediction project uses a historical dataset containing applicant information and their corresponding credit card approval status. The dataset serves as the foundation for training a Machine Learning model capable of predicting whether a new applicant is likely to be approved or rejected.

The dataset consists of demographic, financial, and employment-related attributes that influence credit card approval decisions.

---

## Dataset Characteristics

| Attribute | Description |
|------------|-------------|
| Dataset Type | Structured Tabular Data |
| Format | CSV |
| Target Variable | Approval Status |
| Task | Binary Classification |

---

## Features

The dataset contains several applicant-related features, including:

- Gender
- Age
- Marital Status
- Number of Dependents
- Education Level
- Employment Status
- Annual Income
- Credit History
- Existing Loans
- Property Ownership
- Residence Type

These features help the Machine Learning model identify patterns associated with approved and rejected applications.

---

## Target Variable

The target variable indicates whether a credit card application is approved.

| Value | Meaning |
|--------|---------|
| 1 | Approved |
| 0 | Rejected |

---

## Data Quality

Before training the model, the dataset was examined for:

- Missing values
- Duplicate records
- Outliers
- Incorrect data types
- Inconsistent values

---

## Importance of the Dataset

A high-quality dataset enables the model to learn meaningful relationships between applicant characteristics and approval outcomes, ultimately improving prediction accuracy and reliability.
