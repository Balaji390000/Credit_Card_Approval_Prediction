# Model Evaluation

## Overview

The trained model was evaluated using standard classification metrics to measure prediction performance.

---

## Evaluation Metrics

| Metric | Description |
|---------|-------------|
| Accuracy | Overall prediction correctness |
| Precision | Correct positive predictions |
| Recall | Ability to identify positive cases |
| F1 Score | Balance between precision and recall |

---

## Confusion Matrix

The confusion matrix provides insight into:

- True Positives (TP)
- True Negatives (TN)
- False Positives (FP)
- False Negatives (FN)

The selected model achieved reliable prediction accuracy and demonstrated good generalization on unseen data.
