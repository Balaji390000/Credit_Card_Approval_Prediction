# Non-Functional Requirements

## Overview

Non-functional requirements define the quality attributes and performance standards of the system.

---

# Performance

- Prediction time should be less than 2 seconds.
- The application should load quickly.
- Data preprocessing should be efficient.

---

# Reliability

- The prediction model should produce consistent results.
- The application should remain operational without crashes.
- Proper exception handling should be implemented.

---

# Accuracy

- The model should achieve high prediction accuracy.
- False approvals and false rejections should be minimized.

---

# Scalability

The system should support:

- Larger datasets
- Additional prediction models
- Cloud deployment
- Multiple concurrent users

---

# Security

- Input validation
- Protection against invalid requests
- Secure deployment
- No unauthorized data access

---

# Usability

The system should:

- Be easy to learn.
- Require minimal user training.
- Provide clear instructions.
- Display understandable prediction results.

---

# Maintainability

- Modular code structure
- Well-documented code
- Easy model replacement
- Easy feature enhancement

---

# Availability

The web application should be available whenever users access it.

---

# Portability

The application should run on:

- Windows
- Linux
- macOS

with minimal configuration.
