## 📖 Project Overview

The **Credit Card Approval Prediction System** is a Machine Learning-based web application that predicts whether a customer's credit card application is likely to be **Approved** or **Rejected** based on applicant information.

The project automates the traditional credit approval process, reducing manual effort while improving consistency and decision-making. It is built using **Python**, **Scikit-learn**, and **Flask**, providing users with an interactive web interface for real-time predictions.
