# Stakeholders

## Primary Stakeholders

| Stakeholder | Role |
|--------------|------|
| Bank Manager | Uses prediction results |
| Loan Officer | Reviews applications |
| Customers | Apply for credit cards |
| System Administrator | Maintains application |
| Data Scientist | Builds ML model |
| Developer | Develops Flask application |

---

## Secondary Stakeholders

- Financial Institutions
- Banking Analysts
- Auditors
- Regulatory Authorities

---

## Stakeholder Responsibilities

### Customers

- Submit applicant details.

### Bank Officers

- Verify application.
- Review prediction.

### Administrator

- Maintain system.
- Monitor performance.

### Developer

- Improve application.
- Fix bugs.
- Update models.
