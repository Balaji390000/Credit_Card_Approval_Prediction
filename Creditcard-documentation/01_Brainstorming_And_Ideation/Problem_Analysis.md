# Problem Analysis

## Introduction

The credit approval process plays an important role in banking and financial institutions. Incorrect approval decisions may result in financial losses, while unnecessary rejection affects customer satisfaction.

---

## Root Causes

| Problem | Cause |
|----------|-------|
| Slow Processing | Manual verification |
| Human Errors | Subjective decision-making |
| Inconsistent Results | Different evaluation criteria |
| Financial Risk | Incorrect applicant assessment |
| Customer Delay | Long approval process |

---

## Challenges

- Large amount of applicant data.
- Missing values in datasets.
- Imbalanced classes.
- Feature dependency.
- Model selection.
- Prediction accuracy.

---

## Impact

### For Banks

- Increased operational cost
- Financial losses
- Poor resource utilization

### For Customers

- Delayed approval
- Customer dissatisfaction
- Reduced trust

---

## Opportunity

Using Machine Learning enables automated, scalable, and data-driven decision-making, reducing risk while improving processing speed.
