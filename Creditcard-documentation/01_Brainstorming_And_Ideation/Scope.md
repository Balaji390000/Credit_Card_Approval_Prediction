# Scope

## Project Scope

The project focuses on predicting credit card approval using historical applicant information.

The application allows users to enter applicant details and receive an instant prediction.

---

## In Scope

- Data preprocessing
- Feature engineering
- Machine Learning model training
- Prediction system
- Flask deployment
- User-friendly interface

---

## Out of Scope

- Live banking integration
- Online verification
- Real-time credit bureau access
- Fraud detection
- Mobile application

---

## Future Expansion

- Deep Learning implementation
- Cloud deployment
- Real-time API integration
- Credit score calculation
